# Laxmi Engineering — HTML website

Extract the entire ZIP into a folder, then open **index.html** in Chrome or Edge. The main machinery website opens immediately. Choose **Login** in its menu to create quotations with the credentials supplied in the chat.

No launcher, Node.js installation, terminal or local server is required. Keep the HTML, CSS, JavaScript and assets together.

## Quotations

Enter party details, add items and optional images, apply GST when needed, and upload the actual authorized signature. Save quotations to the current browser, reopen them under Saved quotations, or use Print / Save PDF and choose Save as PDF. Select A4 and turn off browser headers and footers for the cleanest output.

Saved records and images are stored in browser storage on this device. Use the same browser profile and the same extracted folder to reopen them. Private browsing, clearing browser data or moving the website can make existing records unavailable. Save important quotations as PDFs.

The standalone login is a local convenience screen, not secure server authentication. The HTML edition does not provide shared online storage or multi-user access. A server is required for those features.

The machinery showcase, horizontal workspace header, quotation form, GST calculations, company details, bank information, terms, optional item photos and signature upload are included. No signature image was supplied, so upload the genuine signature when required.
